# Calculadora ET403 con conversor (Semana 9)

Proyecto del curso ET403 · TPI/TPG 2 · Semana 9.
Mejora la calculadora de la semana 7 con un conversor de unidades.

## Uso
1. Abrir el sitio publicado (enlace más abajo).
2. **Calculadora:** escribir dos datos, elegir Sumar o Dividir y pulsar *Calcular*.
3. **Conversor:** escribir un valor, elegir la conversión (m↔cm, kg↔g) y pulsar *Convertir*.
4. Se rechazan campos vacíos, textos que no son números y valores negativos.
